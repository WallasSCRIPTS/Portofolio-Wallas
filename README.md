# Portofólio Wallas

Portfólio de graphic design, arte 3D e experiências digitais, desenvolvido com React e Vite.

## Desenvolvimento

```powershell
cd portofolio
npm install
npm run dev
```

## Verificações

```powershell
cd portofolio
npm run build
npm run lint
```

Os projetos e seções do site estão em `portofolio/src`.
